# V2 Phase 2 — Multi-Domain Readiness

Status: **IMPLEMENTED**.

Readiness remains a current, revocable projection. Every catalog operation is
independently `SUPPORTED`, `BLOCKED` or `UNSUPPORTED`. Evaluation repeats exact
dataset identity, source fingerprint, profile/mapping/registry identity, stable
column IDs, domain, adapter/Core compatibility, required roles, critical value
mappings, qualifiers, currency, dates and minimum executable data.

Counts do not require optional dimensions or monetary comparability. Summary can
remain supported when supplier/customer/status/reference semantics are absent.
Grouping requires only its fixed role. Aging and overdue require the complete
reference-state contract. Cash category/account roles affect only their matching
operations.

Execution reauthenticates artifacts and applies the same adapter gates; readiness
is not a token. Mapping rejection, source/schema change or qualifier loss revokes
the relevant operation; a newly confirmed current mapping can restore it.

Forecasting and document retrieval remain `BLOCKED`.
